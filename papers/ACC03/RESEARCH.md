# ACC03：分块惯性、Bregman几何与凸随机加速

高雪，《几类优化问题的加速算法研究》，南京师范大学博士论文，2021，114页。主体印刷页=PDF−11。身份见[manifest](../../sources/manifest.json)，阅读覆盖见[日志](../../sources/READING_LOG.md)。第3、4、5章分别蒸馏；以下“作者定理”不等于全文逐行独立复证。被引PALM、iPALM、ASAP及随机方法的历史比较按本文转述，未另外读取其全文作查新。

## 1. 问题选择与公共接口

引言PDF11–17/印0–6、预备知识PDF18–28/印7–17围绕“什么项容易求邻近子问题”选择分裂。PALM把非光滑项留在分离的F、G中，线性化光滑耦合H；ASAP反过来保留双凸H的分块子问题，线性化光滑F、G。Bregman几何用核函数适应可行域和相对曲率，随机有限和则减少一次梯度的样本工作。这三种问题选择不同，不因都有惯性就共享一套定理。

- `D_h(x,y)=h(x)−h(y)−⟨∇h(y),x−y⟩`一般不对称。Legendre/广义Legendre性质给内部可微性与边界行为；严格凸给子问题唯一性；强凸才给`D_h≥μ_h||x−y||²/2`。三者不可替换（§2.2）。
- 非凸GL-smad要求`Lh±F`凸，因此`|D_F(x,y)|≤L D_h(x,y)`；凸相对光滑只需`Lh−F`凸（§2.3）。有界集上的梯度Lipschitz也是额外正则性，不能由C¹自动推出。
- 三角缩放是`D_h((1−θ)x+θz,(1−θ)x+θw)≤θ^γD_h(z,w)`（PDF23–24），γ由核和域决定，欧式平方核为2；不能对所有熵核沿用2。
- KL统一化把下降量与次梯度连接为有限长度；有界性产生紧聚点集；函数值沿子列的连续性/收敛与次微分闭性把极限转成驻点。平方步差可和本身不保证全序列收敛。
- 偏次梯度分别为零不自动是联合驻点。第4章特别要求`∂_xH×∂_yH⊂∂H`，再补函数值与跨块正则性；分块计算不等于网络通信算法。

## 2. 第3章GiPALM：Gauss–Seidel惯性中心

### 模型、完整更新与参数

模型(3.1.1)，PDF29–31/印18–20：`min Ψ(x,y)=F(x)+G(y)+H(x,y)`，x∈Rⁿ、y∈Rᵐ。F/G正常下半连续、可非凸非光滑且下有界；H光滑耦合，Ψ下有界。假设3.1要求固定另一块时偏梯度有L₁(y)、L₂(x)，沿轨道有正下界及有限上界`λ_i^-≤L_i≤λ_i^+`，全梯度在所需有界集上M-Lipschitz。近邻限制是iPALM的外推/邻近中心处理与参数约束；本章用同一惯性中心并在第二块使用新外推第一块。

算法1：`x̄⁰=x⁰,ȳ⁰=y⁰`，α、β∈[0,1)，k=0起依次

`x^{k+1}∈prox_{F/c_k}(x̄^k−∇_xH(x̄^k,ȳ^k)/c_k)`；
`x̄^{k+1}=x^{k+1}+α(x^{k+1}−x̄^k)`；
`y^{k+1}∈prox_{G/d_k}(ȳ^k−∇_yH(x̄^{k+1},ȳ^k)/d_k)`；
`ȳ^{k+1}=y^{k+1}+β(y^{k+1}−ȳ^k)`。

这里减的是旧外推中心x̄/ȳ，不能替换成通常的旧主迭代点。非凸prox可能多值，应记录所选全局子问题解；α=β=0退化为PALM结构。

推论3.2.1（PDF34–35）给一种足够参数选择。记`A_α=(1−ε)−(1+ε)α²`、`A_β=(1−ε)−(1+ε)β²`，取`0<ε<1,0<α,β<sqrt((1−ε)/(1+ε))`：

`δ₁=(1+α)²(λ₁⁺+M)/(2αA_α)+(1+β)α²M/(2βA_α)`；
`δ₂=(1+β)²(λ₂⁺+M)/(2βA_β)+(1+α)M/(2αA_β)`；
`c_k=2(1+ε)α²δ₁+(1+α)λ₁⁺+Mα+(1+β)α²M/β`；
`d_k=2(1+ε)β²δ₂+(1+β)λ₂⁺+Mβ`。

零惯性须走非惯性基线，不能代入含1/α、1/β的此组公式。较大惯性使可容许的步长/近端惩罚同时变化；不能只把α增大解释成保证更快。

### 证明链与对象

势能`S=Ψ+δ₁||x−x̄||²+δ₂||y−ȳ||²`（PDF35–44）：

| 入口 | 核心作用 |
|---|---|
| 引理3.2.1及推论3.2.1 | 子问题最优性+偏梯度下降+Young不等式，选择c/d与δ吸收惯性交叉项 |
| 引理3.2.2 | `ρ₁(||z^k−z̄^k||²+||z^{k+1}−z̄^{k+1}||²)≤S^k−S^{k+1}`，ρ₁=εminδ_i；得到平方误差与平方步差可和 |
| 引理3.2.3 | 构造`A^{k+1}∈∂S`，用M、λ_i和惯性恒等式界为常数乘`||z̄^{k+1}−z^{k+1}||` |
| 引理3.2.4 | 有界轨道→紧非空聚点集；子问题比较与下半连续性使F/G值沿子列收敛；再用次微分闭性认出驻点，S在聚点集为常值 |
| 定理3.2.1，PDF41/印30 | KL统一化+上述两界→`Σ||z^{k+1}−z^k||<∞`，整个序列收敛到Ψ的驻点 |

定理要求所述参数、假设和有界轨道；原文将Ψ为KL推及S，调用时应核具体函数类的S也满足KL（例如本章半代数算例）。这不是全局最优点或函数差O(k⁻²)结论，也未给显式优于去惯性方法的条件数率。PDF30注3.1.1将H的C¹当作全梯度局部Lipschitz的充分理由并不成立，保留假设3.1(iv)为独立条件。

## 3. 第4章：先区分IASAP与IASAPL/ASAPL

### IASAP（§4.1，PDF53–66/印42–55）

同形式Ψ，但F/G光滑可非凸，H正常下半连续且双凸；Ψ下有界，∇F/∇G分别L_F/L_G-Lipschitz（假设4.1）。初始化与第3章相同，算法2依次

`x^{k+1}=argmin_x {H(x,y^k)+⟨∇F(x̄^k),x⟩+||x−x̄^k||²/(2τ)}`；
`x̄^{k+1}=x^{k+1}+α(x^{k+1}−x̄^k)`；
`y^{k+1}=argmin_y {H(x^{k+1},y)+⟨∇G(ȳ^k),y⟩+||y−ȳ^k||²/(2σ)}`；
`ȳ^{k+1}=y^{k+1}+β(y^{k+1}−ȳ^k)`。

第二块保留H时用新x主点，不是GiPALM的新x̄。非惯性ASAP是α=β=0。证明在PDF56选`τ=1/(2L_F),σ=1/(2L_G)`；令`M₁=(3/2+1/α²)L_F/2`、M₂同理，`0<α²,β²<2/3`使两侧惯性系数之间有正下降余量ρ。零惯性另按ASAP分析，F≡0时可选正的L_F上界而非除以零。

引理4.1.2给S下降、平方步差可和以及`min_{0≤k≤K}||z^k−z̄^k||²≤(S⁰−S*)/[ρ(K+1)]`。由于初始化z⁰=z̄⁰，此历史最小量从k=0起时甚至为0；不能据它报告非平凡的末点目标差率。实际停机宜检查驻点残差。

假设4.2要求联合次微分包含、domH闭，及连续性或`H=φ+w(x)`的跨块正则性；定理4.1.1（PDF64）明确用(iv)(A)的`∇_xφ`关于y局部Lipschitz。它将旧y处的偏次梯度转到同一新点，得到完整∂S误差界，再以KL+有界性证明有限长度和全序列驻点收敛。仅用连续性可讨论聚点，不能自动取得该定理的误差界。

### IASAPL与ASAPL（§4.2，PDF67–80/印56–69）

在开凸域X、Y的闭包上最小化Ψ；假设4.3：Ψ下有界且强制，F/G正常下半连续可非凸，H双凸；严格凸广义Legendre核h/ψ；(F,h)、(G,ψ)为GL-smad，常数L_h/L_ψ；Bregman趋零与相应点收敛的兼容条件(v)。强制性服务于有界水平集和子问题存在性，严格凸给唯一解，核的内部定义保证合法计算。

算法3：`x^{-1}=x⁰∈int domh,y^{-1}=y⁰∈int domψ,0<η,θ<1`。每轮选`α_k⁰,β_k⁰∈[0,1),0<τ_k<1/L_h,0<σ_k<1/L_ψ`，记`C_k¹=1/(1+τ_kL_h),C_k²=1/(1+σ_kL_ψ)`：

1. 最小j≥0使外推点在核域内，且`D_h(x^k,x^k+η^jα_k⁰(x^k−x^{k−1}))≤θC_k¹D_h(x^k,x^{k−1})`。置α_k=η^jα_k⁰、`x̄^k=x^k+α_k(x^k−x^{k−1})`。
2. `x^{k+1}=argmin_{x∈X̄}{H(x,y^k)+⟨∇F(x̄^k),x−x̄^k⟩+D_h(x,x̄^k)/τ_k}`。
3. 对y作同样回缩检验得到β_k、ȳ^k，更新`y^{k+1}=argmin_{y∈Ȳ}{H(x^{k+1},y)+⟨∇G(ȳ^k),y−ȳ^k⟩+D_ψ(y,ȳ^k)/σ_k}`。

这里的惯性用前一主点，与GiPALM/IASAP的递归中心不同。`α_k⁰=β_k⁰=0`是ASAPL。回缩因子控制的是Bregman惯性能量，不能称无线搜索。命题4.2.1/2说明子问题与回缩的良定义，内部点附近开域及连续性用于有限终止；数值实现仍需域检查和失败处理。

引理4.2.1先保留反向步差`D_h(x^k,x^{k+1})/τ_k`，再用对称系数`a_h=inf D_h(u,v)/D_h(v,u)`转成正向项。PDF73进一步要求**正步长下界**与有限上界，以及

`0<θ<min{τ_lower a_h/τ_upper, σ_lower a_ψ/σ_upper}`。

令`M₃=(θ/τ_lower+a_h/τ_upper)/2`、M₄同理；`J^k=Ψ(z^k)+M₃D_h(x^k,x^{k−1})+M₄D_ψ(y^k,y^{k−1})`。引理4.2.2给下降与

`min_{0≤k≤K}{D_h(x^{k+1},x^k)+D_ψ(y^{k+1},y^k)}≤(J⁰−J*)/[δ(K+1)]`。

这是历史最小Bregman步差和；δ取两个正余量中的最小值，含核不对称性和步长界。若全域a_h=0，则该正θ区间为空，不能省略条件后宣称全域速率。以一维Burg核为例，`D_h(r,1)=r−ln r−1`、`D_h(1,r)=1/r+ln r−1`；交换顺序并令r→∞，比值趋0，故全正半轴a_h=0。若限制到紧内部域，则须重新给有效局部界。

**命名核实：PDF76/印65明确说IASAPL全局收敛尚在探索；定理4.2.1及4.2.2（PDF76–78）确实针对ASAPL，不能把标题改成IASAPL。** 后一定理还要假设4.4：强凸核、F/G梯度在相关有界集Lipschitz、核梯度可微并局部Lipschitz，假设4.2(iv)(A)、J为KL和有界轨道。强凸将Bregman下降转成欧式步差；光滑核及跨块正则性构造次梯度界；KL闭合有限长度。

调用限制：命题4.2.3的PDF75印刷向量第三、四分量少M₃/M₄，常数写τ_k而证明出现1/τ_k，并有φ/ψ混名；应保留结构而非逐字复用数值常数。定理4.2.1在PDF77由极限内积推出有限k法锥包含的边界步骤不足，且出现h与∇h混写；一般边界驻点结论未在本批独立补齐。内部聚点、相应梯度连续的调用范围更明确。没有把这些局部问题扩展为全篇修复任务。

## 4. 第5章：独立的凸随机有限和路线

### 模型与算法（PDF86–94/印75–83）

`min_{x∈X̄} Φ=F+g, F=n^{-1}Σ_i f_i`，n为样本数、x∈Rᵈ。各f_i凸且在int domh连续可微，g正常下半连续凸，domg与核内部相交，Φ下有界；定理另使用最优点x*。`L_i h−f_i`凸，L为L_i均值。它不是第3/4章非凸模型的随机版保证。

PLSG算法4：`x^{-1}=x⁰∈int domh,0<η<1/L`，对k=0,…,m−1，
`x^{k+1}=argmin_{x∈X̄}{g(x)+⟨v_k,x−x^k⟩+D_h(x,x^k)/η}`。
PLSGmb取均匀mini-batch的平均样本梯度；为保证证明中的消项，需要给定历史后条件无偏及当轮新抽样，而非仅无条件平均相等。输出可选末点或`x̃=(m+1)^{-1}Σ_{k=0}^m x^k`，本文只分析平均点。

PLSGvr算法5在外轮快照x̄计算全梯度v̄，再内轮随机i_s，原页PDF88实际写
`v_s=(∇f_{i_s}(x̄^s)−∇f_{i_s}(x̄))/n+v̄`，并以它作上述prox步，最后写`x^k=x̄^l`。按文中均匀单样本与平均目标定义，其条件均值是`(∇F(x̄^s)−∇F(x̄))/n+∇F(x̄)`，通常不等于∇F(x̄^s)；快照外轮赋值也有索引歧义。此处不静默删除1/n并称原法复现，mini-batch定理不能替这个VR印刷实现背书。

A²PLSG算法6：`z⁰=x⁰∈int domh`，选择θ_k∈[0,1]、α_k>0、β_k>0及φ_k，

`u^k=(1−θ_k)x^k+θ_kz^k`；
`z^{k+1}=argmin_{x∈X̄}{g(x)+⟨v̄_k,x−u^k⟩+α_kD_h(x,z^k)+β_kD_{φ_k}(x,z^k)}`；
`x^{k+1}=(1−θ_k)x^k+θ_kz^{k+1}`。

mb用u^k处的mini-batch梯度；vr仅按前述方差缩减思路命名，未给另一套完整独立定理。自适应是变化度量φ_k，与ACC02用局部曲率确定步长的信息规则不同。进行条件期望消项时，度量及全梯度辅助点还必须对当轮样本独立/可预测；任意依赖本轮噪声的度量不能无条件套用该证明。

这里`δ_k=v̄_k−∇F(u^k)`，`R_k*=D_{φ_k}(x*,z^k)−D_{φ_k}(x*,z^{k+1})`，

证明方法的正向价值：PLSG引入与当轮样本无关的“全梯度虚拟prox点”，用强凸性界随机点与虚拟点距离，再把相关噪声内积分成可消条件均值和二阶矩项（PDF89–91）。A²版本用三角缩放把插值后的D_h转回z步，用变化度量项单独记账。该做法有助于先识别误差来源，再决定是否值得加入自适应结构。

使用限制：PLSG平均点证明把k=0也套前一步递推，存在初始索引缺口（PDF92）；本批只保留原报告的界形与证明方法，不把原常数当已认证。定理5.2.3的距离假设写x^k，而度量望远镜涉及z^k，直接调用须核相应z距离；此处未补新定理。§5.4对若干熵核一概否定强凸性须结合域/范数判断，本库不继承该泛化说法。

## 5. 可执行正向方法与候选增量

**先按可解子问题选分裂，再以能量确定惯性范围。** 对给定模型列F/G/H及其prox代价：若耦合梯度易算而分离prox易解，选PALM式；若耦合分块prox容易，选ASAP式；若欧式曲率无界但能显式验证`Lh±F`凸，才进入Bregman。接着分别建立下降、同点次梯度界和边界/聚点条件，最后决定需不需要KL。执行方式见[紧凑E03协议](EXPERIMENTS.md)，本轮未运行性能比较。

对C2：相对光滑Bregman和非凸惯性分块已经有丰富结构，不能把“换核+平滑+惯性”列为差异；IASAPL的历史步差也不能给变μ原目标差率背书。C2收缩到可证明凸性的线性复合损失基础，具体研究接口是同参数重评与跨参数漂移证书及总成本。到P00非凸弱凸路线须另给合适驻点量、平滑梯度一致性和有界/边界条件；到分布式须另建信息与误差关系。
