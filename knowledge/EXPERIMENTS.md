# 本批实验与复算契约

适用于本批的算法核验和未来候选小验证；是执行者归纳，不是所有研究的固定测试清单。

| 要回答的问题 | 所需前提与操作 | 检查/失败处理 |
|---|---|---|
| 某条关键递推是否有效 | 原页确认符号、固定合法参数与判据，尽量用精确小例；见V01 | 保存原值/输出及边界；违反只否定局部关系，先隔离依赖它的判断 |
| 动量是否减少工作 | 同一目标、归一化、初值、误差证书和调参预算；β=0成对控制 | 同时报样本调用、初始化、通信、缓存和时间；epoch不明则不跨实现排名 |
| 无线搜索是否更省 | ACC02缓存时序，逐次计f/梯度，探测初始化和基线试探 | 不把无搜索写成无参数或无函数评价；相同精度下比较总工作 |
| 平滑是否解原问题 | 原目标和随τ变化的近似分开，计算偏差+优化差 | 生成点目标值不是自动最优值；理论速率对象不得替换 |
| 误差oracle能否迁移 | 明确噪声/确定误差、上界可得性、带权能量残差 | 随机无偏不等于路径精确；先证明证书，再设计性能实验 |

## 第二批新增契约

原实验审查覆盖ACC03信号/图像/NMF、QP/Poisson、两数据集logistic与ACC04三损失六图。ACC03定轮质量提高却耗时更高，ACC04生成参考值缺最优性证书：前者促使同精度计总工作，后者促使显式保留参考值性质。两种限制不能靠给图加更多方法消除。

新协议[ACC03 E03](../papers/ACC03/EXPERIMENTS.md)为固定非凸标量分块、3配置×2初值=6单元，以完整驻点残差停机；[ACC04 E04](../papers/ACC04/EXPERIMENTS.md)为有解析最优值的8维凸问题、4配置×2初值=8单元，以原目标相对gap停机。均无调参补试、失败保留、诊断成本分列，均**未执行**。它们是本轮问题所需的紧凑协议，不照搬首批参数网格。

V02使用Fraction，实际验证62条有限关系与边界；其中混合证书严格失败是预定的边界结果，整体退出成功表示核验按判据完成，不能误读为混合算法通过。完整原件/页图、实验大数据与凭据继续留Git之外。
