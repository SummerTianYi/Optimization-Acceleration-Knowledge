# 本批写作方法

来源是 [ACC01写作](../papers/ACC01/WRITING.md) 和 [ACC02写作](../papers/ACC02/WRITING.md)，均为执行者归纳；示例中的英文全部自行改写。

1. **以具体障碍组织引言。** ACC01适合按信息缺口解释跟踪、缓存和惯性；ACC02按已有方法已经得到的函数率，指出还缺点收敛与强凸结论。条件：近邻已解决的内容须准确，未回查就标作者转述。检查：贡献句能否写出改变的模型/信息/结论对象。不能靠“研究很少”证明空白。
2. **公式旁说明它服务哪一步。** 状态量说明哪个误差，能量说明保留哪些耗散，参数门说明消除哪个剩余项。条件：确有对应推导。检查：每个“因此”两侧假设和下标一致。ACC01首项错误说明结构清楚仍需数学检查；ACC02的三门结构可作正向范例。
3. **把证据强度放进动词。** “作者证明”“本轮精确反例”“图中观察”“尚待证明”不混用。函数gap、点弱收敛、线性指数与最优条件数依赖分别写。条件：先有研究卡的模型/定理表。检查：不让摘要比正文更强，结论与展望一致。
4. **区分事实校准与同事实组织。** 纠错、补假设、补比较口径或限制会改变事实集合，标为“事实校准”；两篇旧例属于此类。真正的同事实练习先固定3–5条带原文定位的共同事实，两版都准确且完整保留它们，只改顺序、衔接和解释组织。两篇新增练习分别固定A1–A4、B1–B4；必要条件不能仅出现在后版，弱收敛也不能在改写时变成范数收敛。没有实验的论文讨论理论链，不制造数值结果。
5. **按语境保留必要条件。** 独立的摘要、定理或结论需要足以确定数学含义的假设；上下文已经明确后，后文可使用这些条件，避免逐句重复。严谨性取决于适用域和结论是否清楚，不取决于限定语数量。自然性检查关注论证顺序、衔接和表达密度，不建立词语黑名单。
6. **把审查记录留在内部。** 假设表、反例、风险和执行状态可在研究卡详细保存。论文范例只写当前论证所需的信息。反向审查时尝试删去重复的条件、否定和解释，再核事实与数学含义：ACC01把两段公式复述合为并列更新，ACC02直接并列函数率与弱点收敛；具体前后对照及保留理由在两篇WRITING。删减若造成实质歧义，就恢复必要条件。

使用顺序：选有页码的片段→必要时先做事实校准→固定共同事实与语境→组织改写→核事实及数学含义→反向删减重复防御。事实ID、自动比对和自然性审查属于内部记录；最终范例使用连贯论文表达。本轮人工核对两版的事实和必要条件，机械检查辅助核公式、条件句与来源。P00要求研究证据与复杂度，本库不产导师汇报。

## 第二批：用新的论证语境检验

- [ACC03](../papers/ACC03/WRITING.md)以NMF“固定预算下的质量与时间取舍”练习：前版500轮→差距→50轮，后版取舍→50轮→500轮→差距。四条事实和数字不变；将连续否定压成“以更长运行时间获得较高质量”，仍保留预算条件。另一原文片段分析下降、次梯度、聚点与KL的承接。
- [ACC04](../papers/ACC04/WRITING.md)以“平滑偏差如何传递到原目标”练习：把先给结论后补依据改为偏差→原gap→求解安排。同μ/同可行集与有限最优值放共同语境，段内保留2κμ和L/μ的因果解释。内部端点问题和模型反例不挤进范文。

本批两组S1–S4用于局部语义核对，不升级为正文固定模板。自然性反向审查分别有具体删改及数学必要性说明；机器只检查事实数字/公式与片段完整性，不能证明自然性。英文练习均为执行者新写，建议与已观察事实分开。
