# 本批写作方法

来源是 [ACC01写作](../papers/ACC01/WRITING.md) 和 [ACC02写作](../papers/ACC02/WRITING.md)，均为执行者归纳；示例中的英文全部自行改写。

1. **以具体障碍组织引言。** ACC01适合按信息缺口解释跟踪、缓存和惯性；ACC02按已有方法已经得到的函数率，指出还缺点收敛与强凸结论。条件：近邻已解决的内容须准确，未回查就标作者转述。检查：贡献句能否写出改变的模型/信息/结论对象。不能靠“研究很少”证明空白。
2. **公式旁说明它服务哪一步。** 状态量说明哪个误差，能量说明保留哪些耗散，参数门说明消除哪个剩余项。条件：确有对应推导。检查：每个“因此”两侧假设和下标一致。ACC01首项错误说明结构清楚仍需数学检查；ACC02的三门结构可作正向范例。
3. **把证据强度放进动词。** “作者证明”“本轮精确反例”“图中观察”“尚待证明”不混用。函数gap、点弱收敛、线性指数与最优条件数依赖分别写。条件：先有研究卡的模型/定理表。检查：不让摘要比正文更强，结论与展望一致。
4. **同事实改写优先于套话替换。** 修改前后保持事实集合，只补齐模型、比较口径和限制。没有实验的论文讨论理论链，不制造数值结果。P00要求的是研究证据与复杂度；本库不产导师汇报材料。

使用顺序：选有页码的论证片段→列事实和缺失条件→按问题/机制/证据重写→逐句回查来源。不能用文字流畅度抵消数学或执行真实性问题。
