# 从能量到停机成本 · ACC02 可复跑示范

**起步题面。** 对 Wang–Peypouquet 的既有自适应加速法，三道可计算步长门怎样在移位凸二次模型上保证函数差？如果要求在实际输出点交付相同函数精度，是否值得每步再求一次梯度？读者可先看[完整英文稿](NOTE.md)，再按[中文推导](DERIVATION.md)、[固定协议](protocol.json)、[独立核验器](verify.py)复算。本文的 12 维问题是独立审查采用的小族，库内 E02 的 100 维对角协议仍按原历史登记。

**开工约定（早于本次运行）。** 依[通用入口](../../knowledge/RESEARCH_TO_DRAFT.md)第 1 步选 ACC02 的能量法，不借用非光滑或网络结论。第 2 步固定二维正定/奇异推导与 12 维 SPD/PSD、正谱比 100/10000 的 16 单元。H=Q diag(λ)Qᵀ，Q 是向量 (1,…,12) 的 Householder 反射。c 的第 j 项为 (−1)ʲ/4（从零编号），x₀=1，探测点为零。谱在 [1,κ] 几何等距，PSD 前三项为零。配置可换文件；本稿只解释随附配置。更新在同一固定 f 上进行。ACC02、回溯只调用 f、g；固定 Nesterov 和 GD 得到 L=κ。已知 f*=0 用于基准停止，算法推进无需 c 或 f*。初值后每个接受点检查 f/max(1,f₀)≤10⁻⁸，先检查是否达标再准备下一步。发生真正调用前检查预算；失败保留最后可返回点与实际调用，实际停止原因优先于可选观察。

初始及停止所需函数调用、推进（含回溯失败试探和初始探测）、可选输出梯度分别计价。同一向量精确字节缓存最近 8 个首次插入点，同点命中免费。主比较只取返回点及函数证书。固定的敏感性组单独运行，包含预算 900 的同模型两组，保留真实停机与缓存影响。GD 敏感组检验今日监测、多数调用在下次更新复用的情形。矩阵操作按函数一次 Qᵀ、梯度一次 Qᵀ 和一次 Q 计，每个接受的输出向量写入轨迹。模型构造一次反射（一次外积、一次内积）、谱与坐标构造单列；无近端。离线公式核验含梯度/能量重建，其矩阵运算不参与在线总量。报告 f 与 g 分开，合计仅以各一次等权作声明过的预算；没有用耗时排序。

**干净目录运行。** Python 3.12，NumPy（实测 2.3.5）；可在空目录放入本目录的 run.py、verify.py、inputs.json 和 protocol.json，安装 NumPy 后执行以下命令。输出路径必须尚不存在。inputs.json 保存本轮由所列公式生成的实际二进制浮点数的往返十进制表示。不传 --inputs 时按公式在本机生成。载入已存因子时还会校验正交性（一次 QᵀQ）和谱范围，均列为预处理。每个单元单独写 input、summary、CSV。核验器独立读取配置与轨迹。长轨迹留库外；本库保存[精简结果及生成文件哈希](results.json)。

```sh
python run.py --config protocol.json --inputs inputs.json --out run07
python verify.py --run run07 --out verified07.json
```

**使用记录。** 推导先固定曲率与信息可得性，运行前确定上述基线及失败情形。按第 3 步先从真实输出建立[主张—证据](CLAIMS.md)，再写英文稿；第 4 步按行复核摘要、表格和讨论。移植与修改见[输入归属](../../reviews/UPGRADE07_INPUTS.md)。
