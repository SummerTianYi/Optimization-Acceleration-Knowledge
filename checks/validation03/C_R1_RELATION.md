# C-R1：输出、停机与含残差的直接gap

2026-10-31。定位：R01 PDF12–14、23–25（Algorithm4、(37)–(43)、Cor3.5、Lemma5.9、(91)）；R32 PDF8式(2.13)为直接gap望远镜的比较工具。R38为本轮新增2604.18321v1，仅读PDF1–4、9的模型、证书和TAA条款，不作整篇蒸馏。

## 1. 哪些固定、哪些会改变算法

R01的x_{k+1}是内层ACG结果再作一次近端梯度步所得的外层原变量，原算法在梯度映射与可行性同时满足门限时返回它。它是所选终止外步的原变量，不能由“只输出一个向量”推断任何平均点也属于同一非遍历合同。

若输出xbar_K=B_K^−1Σ_{k<K}b_k x_{k+1}，可在线计算，仍在dom h中，但改变了输出规则。固定ρ可减少重复分解；最后点可保留迭代结构，但一般凸h本身并未提供“平均点不能用”的必要性。因此本轮同时分析平均点，不用最后点或固定ρ排除竞争方法。

区分两种任务：①更新、γ_p/γ_d、ε_k和原停止门全固定，只改善可证明的界；②保留更新骨架但改参数/输出/证书停止，属于算法变体，须重新核成本。若只证明较早点的gap小，却仍运行原停止门，不等于总ACG调用减少。本轮不实施②的完整算法。

## 2. 完整的一步关系（执行者推导）

设φ=f+h，x*可行最优，q_{k+1}=Ax_{k+1}−b；写x^+=x_{k+1}、λ^+=λ_{k+1}、vtilde=tildeν_k。原更新λ^+=vtilde+ρq。R01 (91)给

`r_k ∈ ∂φ(x^+)+γ_p(x^+−x₀)+A^T λ^+，‖r_k‖≤ε_k/D`。

对任意测试乘子λ，凸性和三点恒等式给

`φ(x^+)−φ*+⟨λ,q⟩ ≤ ⟨r_k,x^+−x*⟩ + (γ_p/2)[‖x*−x₀‖²−‖x^+−x₀‖²−‖x^+−x*‖²] + [‖λ−vtilde‖²−‖λ−λ^+‖²−‖λ^+−vtilde‖²]/(2ρ)`。 (C.1)

这里保留了非精确交叉项和负项。对原目标负侧另有

`φ(x)−φ* ≥ −⟨λ*,Ax−b⟩ ≥ −‖λ*‖‖Ax−b‖`。 (C.2)

所以单边直接gap不是绝对gap证书。取正权b_k并对(C.1)求和，凸性只直接给**加权平均点**的目标上界，不能把左端改成φ(x_K)。这正是与R32聚合点gap需对齐的输出区别。

## 3. 原预算确实消掉一处D，但未闭合全部加速项

由‖x^+−x*‖≤D及ε_k=(7ε₀a^k+σρε²)/8，

`B_K^−1Σb_k⟨r_k,x^+−x*⟩ ≤ (7ε₀/(8B_K))Σb_k a^k + σρε²/8 ≤ 7ε₀ C_sum/(8B_K)+σρε²/8`， (C.3)

其中C_sum=ΣB_{k+1}a^k<∞是R01 Lemma5.9(d)的预算上界；a为原文α。**D已因内精度ε_k/D抵消**，不能重复02的猜测说残差粗估必然再多一个D。代价在于达到这个内精度以及γ_p所需的ACG工作仍存在。

继续代入(43)，γ_d项准确相消得到

`τ_{k+1}ν_{k+1}=τ_kν_k+b_k q_{k+1}`，
`Axbar_K−b=(τ_Kν_K−τ₀ν₀)/B_K=(B_K^−1+γ_d)ν_K`。 (C.4)

最后一个等号使用原初始化ν₀=0、τ₀=1。即使ν_K有界，也还须控制γ_d‖ν_K‖，不能只保留1/B_K项。

为显示第一处没有直接闭合的望远镜，令ν^+=ν_{k+1}、τ^+=τ_{k+1}，则(C.1)的加权对偶项精确等于

`b_k⟨λ−λ^+,q⟩ = (τ_k/2)‖λ−ν_k‖² − (τ^+/2)‖λ−ν^+‖² − (τ_k/2)‖ν^+−ν_k‖² + (b_kγ_d/2)(‖λ‖²−‖ν^+‖²) + b_k⟨ν^+−λ^+,q⟩`。 (C.5)

前两项可望远镜；最后的加速交叉项一般不为负，不能当成普通ALM的距离差丢弃。R32有其自身更新/聚合势来控制相应项；它的式(2.13)并不是I-FALM的现成定理。R01的FLOrA势目前控制的是正则化对偶及停止条件，尚未在此推出所需平均点直接gap上界。**当前具体断点**是给(C.5)最后项与已知势的有效联合界，同时计入γ_d B_K‖λ‖²/2及原参数；不是内残差项本身无法求和。

## 4. 正则化与原停机可能抵消收益

丢掉(C.1)的两个负原变量项，原始目标偏差上界含γ_pD²/2=εD/4。该量不是只有证明粗糙才出现：在区间[0,D]上令f(u)=(γ_pD/4)u+(γ_p/4)u²、x₀=D。原最小点0；加入γ_p(u−D)²/2后最小点D/2，原目标gap=3γ_pD²/16。它是正则化偏差的解析边界例，可嵌入具有独立等式坐标的凸模型；不是一项完整I-FALM性能运行。

此外(C.2)保留乘子半径与可行性乘积，(C.4)保留γ_d项。若沿用原γ_p=ε/(2D)、γ_d按ε/R设置及Cor3.5的ε=ε_g/[2(D+Rhat)]，就仍为这个较小ε付原停止成本。改善平均点gap的证明不自动减少实际调用。要声称运行更快，须建立可计算新停止证书并量化所需常数，或证明**原停止门本身**更早触发；本轮两者均未得到。

## 5. 同作者后续证书：能做什么、哪里不能照搬

R38 PDF2要求h域有界、w非负1-强凸且在域上有界M_w，GLMO `min_x ⟨v,x⟩+h(x)+αw(x)` 可计算。PDF4 Lemma2.1、Def2.2–2.4用聚合线性下模型Γ，证书为φ_α(u)−minΓ≤ε_g/2，α≤ε_g/(2M_w)。PDF9 Algorithm5/Th5.1给TAA特定三平均更新的Õ(1+√(M_w L/ε_g))次迭代；返回的是其测试平均点y_k。

两种直接尝试要分开：

- 将等式并入h_eq=h+δ_{Ax=b}，模型理论上是CSCO，但GLMO变成带等式的复合近端。R01只承诺prox_h便宜；一般盒约束加稠密A的该子问题是耦合QP，并不由prox_h直接给出。若这个GLMO确实便宜，则R38是应优先比较的成熟替代，而不是保护I-FALM候选的理由。
- 不并入等式，固定λ，将聚合切平面ℓ≤f与h、γ_p‖x−x₀‖²/2及⟨λ,Ax−b⟩组合，其最小值减γ_pD²/2是可计算的原问题最优值下界；二次w时GLMO可由prox_h求。这个证书构造可用，但偏差项仍在，原变量负gap仍须由(C.2)或精确可行输出处理。R38的证书**速率**依赖TAA更新与其线性化点，不能套到现有I-FALM轨道。仅验证定义有效不等于满足原停止门。

因此本次定向读到证书定理就停止，无需扩读博弈应用或整个证明。它既不是所有等式约束的免费替代，也没有为当前I-FALM直接gap课题提供现成的新复杂度结论。
