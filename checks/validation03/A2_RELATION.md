# A2：同精度账与投影加速混合的一步关系

2026-10-31。R24 PDF4–5的模型/引理与PDF10–11的(A.8)–(A.19)是作者原文；以下带“推导”的式子为本轮执行者展开。复用R22 FastMix的多项式混合思想，不宣称设计了新网络优化器。

## 1. 共同合同及可计费基线

固定m个节点，各自持有m_i组(a_ij,b_ij)，f_i(x)=m_i^−1Σ_j |(a_ij^T x)²−b_ij|，C为半径R的共同球，Φ=f+δ_C，f=m^−1Σf_i。取ρ=2max‖a_ij‖²、L_s=ρR、0<t<1/(2ρ)。精度统一为E‖∇Φ_t(x_out)‖²≤ε²，**ε为范数精度**。不比较函数gap或末点梯度。随机性仅用于按步长权重抽取已生成迭代；局部次梯度用全批，记每轮分量工作M=Σm_i。

节点使用同一可行初点，避免把初始共识暂态隐藏进常数。Φ≥0，故Δ≤f(x₀)是可计算初始包络差上界，取得它需一次本地函数值计算和聚合。静态对称非负PSD双随机W，λ=‖W−J‖<1、γ=1−λ。球投影O(d)，与LMO一样不能免费；梯度、投影、通信分别计价。以下省略Δ、ρ、t、L_s和已知范数上界的固定系数，保留图与ε依赖。

|方案|精度达到所需的保守更新数K|总分量次梯度|邻边向量通信轮|
|---|---|---|---|
|R24单轮W，优化步长系数|O(γ^−2 ε^−4)|MK|K，另加一次输出聚合|
|每次W^s，s=O(γ^−1)，使λ^s≤q₀<1|O(ε^−4)|MK|O(γ^−1 ε^−4)，另加输出聚合|
|Chebyshev块后投影，s=O(γ^−1/2)，q≤q₀<1|本节一步关系求和给O(ε^−4)的保守账|MK|O(γ^−1/2 ε^−4)，另加输出聚合|
|精确树聚合的集中投影次梯度|O(ε^−4)|MK|O(d_G ε^−4)，含每次求和及广播|

前三行可共享随机索引、各节点保存选中的局部点，最后聚合成x_out=bar x；最后O(d_G)轮不是零。中央方案在同一x计算全部局部次梯度后平均再投影，和“混合点相同、各自投影后再平均”是不同更新，但证书与总分量工作可直接比较。树无需搬运原数据。d_G≤O(log(m)/√γ)的已核图尺度说明精确聚合已经达到相同图阶（差对数）；当前合同未要求最慢节点计算时间最优或禁止聚合。

原文α_k默认1/√k得到的图系数不能直接当优化后的总复杂度。为给有限预算K统一记账，本节用常数α=a/√K，**只用有限步不等式，不套原无限序列递减步长定理**。若c=(1−2ρt)/2，势函数递推为

`c α Σ_{k<K}‖∇Φ_t(bar x_k)‖² ≤ Δ + K H(q) α²`，

取α=√(Δ/[H(q)K])并限制α≤α_max，则平方范数上界为2√(ΔH(q))/(c√K)。例如K≥4ΔH(q)/(c²ε⁴)且K≥Δ/[H(q)α_max²]足够。单轮H(λ)=O((1−λ)^−2)，合理步长优化后K是γ^−2而非把默认系数平方得到的γ^−4。尚未声称这些上界为下界或最优。

## 2. 负权重、投影及R24第一处关系

将各节点行向量组成X，E=(I−J)X，bar x=m^−1Σx_i。固定多项式P=p_s(W)，P1=1、1^T P=1^T，‖P−J‖≤q<1；P允许负元素。先算U=PX，再取v_i=Π_C(u_i)，**只在v_i处取**g_i∈∂f_i(v_i)，最后x_i^+=Π_C(v_i−αg_i)。多项式块的中间状态可在C外，期间不访问局部次梯度，也不在每个中间轮随意投影而改变多项式。

原文(A.9)、(A.10)使用非负权重的凸组合不等式，不能逐字套给P。但投影非扩张及bar x∈C给

`Σ‖v_i−bar x‖² ≤ q²‖E‖_F²，Σ‖v_i−bar x‖ ≤ √m q‖E‖_F`。 (A2.1)

所以局部次梯度界L_s保留。令s=prox_{tΦ}(bar x)、p_i=prox_{tΦ}(v_i)，c₁=L_s(2−tρ)/(1−tρ)，c₂=2ρ[1+(1−tρ)^−2]。由R24(A.8)的投影步和弱凸不等式，依次拆f_i(p_i)−f_i(v_i)到p_i→s→bar x→v_i，再用prox的(1−tρ)^−1-Lipschitz界，可得

`Σ‖x_i^+−p_i‖² ≤ Σ‖v_i−p_i‖² + 2α[m(ρ−1/(2t))‖bar x−s‖² + c₁Σ‖v_i−bar x‖ + c₂Σ‖v_i−bar x‖²] + m L_s²α²`。 (A2.2)

这是LemmaIII.1所需的一步关系，已明确替换负权重处，而非假设投影仍保持均值。

## 3. 包络平均这一步不能漏

投影通常使bar v≠bar x。只对Φ_t(v_i)在bar x作Taylor展开，会多出未乘α的均值漂移项；但对**带C指示的**包络有更强的直接关系：

`Φ_t(Π_C u) ≤ Φ_t(u)`，因为对每个y∈C，‖Π_Cu−y‖≤‖u−y‖。 (A2.3)

Φ_t在全空间的弱凸模量为ρ_t=ρ/(1−tρ)（对近端定义配方）。R24 LemmaII.8使用的prox Lipschitz关系可扩展到这里的所有锚点：Φ+ρ‖·‖²/2凸，两个prox最优条件的单调性给‖prox(a)−prox(b)‖≤‖a−b‖/(1−tρ)，不要求a、b在C内；由此取安全梯度Lipschitz界M_t=[1+(1−tρ)^−1]/t。先在**未投影U**上展开，Σ(u_i−bar x)=0；结合X处的弱凸下界及(A2.3)，得到

`m^−1ΣΦ_t(v_i) ≤ m^−1ΣΦ_t(x_i) + (ρ_t+M_t q²)‖E‖_F²/(2m)`。 (A2.4)

因此不必用一阶均值漂移界迫使q随ε或m缩小。记Hbar=m^−1ΣΦ_t(x_i)，将(A2.1)–(A2.4)代入R24(A.14)可得

`Hbar^+ ≤ Hbar − c α‖∇Φ_t(bar x)‖² + (ρ_t+M_t q²)‖E‖²/(2m) + α c₁ q‖E‖/(t√m) + α c₂ q²‖E‖²/(tm) + L_s²α²/(2t)`。 (A2.5)

另外‖E^+‖≤q‖E‖+α√m L_s；从共同初点、常数α出发，‖E_k‖≤α√m L_s/(1−q)。于是上一节可取

`H(q)=L_s²/(2t)+L_s²(ρ_t+M_tq²)/[2(1−q)²]+c₁L_s q/[t(1−q)]+α_max c₂L_s²q²/[t(1−q)²]`。

Chebyshev在已知谱上界λ_hat<1下给q≤2exp(−s√(1−λ_hat))的保守尺度；固定q₀即可，本归一化Frobenius账不要求额外log m。若谱上界很松，轮数按该上界计，不能冒称真实γ。精确树聚合的拓扑初始化另付。
