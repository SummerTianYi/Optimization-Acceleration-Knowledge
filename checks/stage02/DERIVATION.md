# V02推导与事先期望

## 合法族与原目标证书

在|x|≤μ内，`h_μ(x)−|x|=(μ−|x|)²/(2μ)`，所以误差在[0,μ/2]；边界±μ与外段的值、导数相合，梯度clip(x/μ,−1,1)为1/μ-Lipschitz且单调。μ方向内部偏导`1/2−x²/(2μ²)∈[0,1/2]`，外段为0，故跨参数函数偏差≤|μ−ν|/2。μ↓0时符合原绝对值及次梯度一致性。

一般双边偏差`|f_μ−f|≤κμ`给`|inf f_μ−inf f|≤κμ`，于是原gap≤近似gap+2κμ。单边`0≤f_μ−f≤κμ`可收紧为+κμ。本例y=1/4、μ=1/2：h_μ(y)=5/16、min h_μ=1/4，近似gap=1/16；原gap=1/4，分别小于9/16和5/16。步长μ后p=0，原gap降为0；光滑上界在此二次段取等号。这个正例检验“先写证书再选步”的方法，不主张完整优化复杂度。

## 两点量为什么需要同一参数

按协议逐项相减即可得两条漂移恒等式。固定ν的凸1/ν光滑函数满足`(Δg_ν)²≤2D_ν/ν`；在同一二次内段D_ν=d²/(2ν)、Δg_ν=d/ν，关系取等号。

对x=1/4、y=3/8、μ=1、ν=1/2：

| 量 | 事先手算 |
|---|---:|
| h_μ(x), h_ν(x), h_ν(y) | 17/32, 5/16, 25/64 |
| g_μ(x), g_ν(x), g_ν(y) | 1/4, 1/2, 3/4 |
| D_ν, Δg_ν, L_same=(Δg_ν)²/(2D_ν) | 1/64, 1/4, 2 |
| 函数漂移, 梯度漂移 | 7/32, 1/4 |
| D_mix, Δg_mix, L_mix | 15/64, 1/2, 8/15 |
| 同ν关系左边(Δg_ν)²、把L_mix代入右边2L_mixD_ν | 1/16, 1/60 |

最后一行是严格失败。它说明混合量不能无补偿替代同ν的这一两点证书，不声称ACC02局部量本来是全域L上界，也不声称把它拼入任何算法都必定发散。

同点边界x=y=1/4：同ν时D_ν=Δg_ν=0，应走等梯度/零分母分支；混合时D_mix=7/32、Δg_mix=1/4、L_mix=1/7。没有空间移动却出现伪曲率，排除了“只减小步长即可忽略漂移”的解释。μ=ν的对照恢复原关系。重评旧点的(h_ν(x),g_ν(x))会消除两种漂移，代价是新增一次该点函数/梯度评价（若联合oracle则一次联合调用）；是否能靠更便宜的可计算漂移界替代，仍待研究。

## 原实验模型的边界

ReLU例：q(−1)=101/100、q(1)=1/100，等权中点0的q=1>51/100。max例：q(−1)=1/100、q(1/2)=1/200，以1/3、2/3加权到0，均值=1/150<q(0)=1。两例b=1可由盒内真值生成，因此目标族不是普遍凸。

线性参考例：A=1/1000、b=A·1、λ=1/100，生成点1的f=1/100；点0的f=1/1000。生成点只是参考值，需另有最优性证书才可把其差称为最优gap。

对候选的直接含义：保留凸平滑基础与原目标证书，收缩C2模型；把“同ν重评/同时补偿函数与梯度漂移”列为下一条关键证据。ACC03的非凸驻点/Bregman步差工具不能直接填补这个时变凸函数差接口。
