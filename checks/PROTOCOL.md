# V01：ACC01 式(4.1)的一步一致性关系

状态：本协议先于脚本首次运行落盘。检验对象是原文 PDF28/印19 式(4.1)，不是完整算法性能或一般收敛定理。公式与 PDF29/印20 式(4.3)、PDF35/印26 矩阵均已看页图。

原文待检关系：C₁ ≤ (1−σ²)C₀/2 + 4α²T₀/(1−σ²) + 4β²D₀/(1−σ²)。C 是堆叠变量的一致性平方误差，T 是跟踪一致性平方误差，D 是步差平方。另算 Young 推导对应的 (1+σ²)/2 系数，仅作局部对照，不认证修订后的全篇定理。

固定输入见 config.json。两个节点、每节点一个样本、标量变量；f₁(x)=(x−1)²/2，f₂(x)=(x+1)²/2，f=(f₁+f₂)/2。μ=1，使用有效但不紧的 Lf=2，Q=2，p=P=1。W=[[9/10,1/10],[1/10,9/10]]，σ=4/5。x₀=(1,−1)，x₋₁=x₀，缓存放在 x₀，g₀=y₀=(0,0)。x₋₁ 的设置是执行者为缺失初值作的显式补全；只按无歧义的向量式(3.12)计算第一步。无随机误差，无需种子。

α=(p/P)(1−σ²)²/(560 Q Lf)，β=10⁻⁶。运行时核 μ<Lf、正定/双随机 W 的谱量，以及 α 小步长条件和 PDF38/印29 四个 β 上界的平方关系。由于初始跟踪和步差为零，首步判断不依赖缓存后续的歧义。

预定判据：精确有理数 lhs>printed_rhs 就否定该条关系的普遍有效性；lhs≤derived_rhs 只说明这个例子满足局部推导版本。不能推断算法发散、加速失败或任何新方法成立。

边界：σ=0、1/2、4/5、99/100 的纯混合；阈值用 r=σ²=1/3 的代数代入检验（不声称有理权矩阵实例）；σ=1 的交换矩阵单列，图连通且双随机但不满足 σ<1，分母为零，不纳入定理内反例。σ=0 时 Young 参数公式含除零，应直接用完全平均投影关系。

实现采用 Python 标准库 Fraction。脚本的断言校验本次复算预期，不把“断言通过”称为论文通过。JSON 保存所有分数，浮点仅辅助阅读；stdout 保存命令执行结果。results/environment.json 记录真实运行时、源代码和配置哈希。复跑只需 Python 3.9+，无第三方依赖。

命令（仓库根）：`python checks/verify_acc01_relation.py --config checks/config.json --output checks/results/acc01_relation.json`。本机实际解释器与命令另见 results/environment.json。
